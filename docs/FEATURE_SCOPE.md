# 功能範圍與接續開發記錄

本次需求：參考 Kaiboard 的功能，中文輸入以**速成**為主，保留中英混合輸入。使用者表示「所有」，再確認「速成就得」。不新增其他中文輸入法；現有倉頡選項保留，首次安裝預設關閉。

## 已有及本次補齊

| 功能 | 0.3.0 狀態 |
|---|---|
| 速成首尾碼、香港常用字 | 保留，可左右捲動選字 |
| 連續速成整句候選 | 保留，`ofvdrf` → 你好嗎 |
| 逐字改選 | 保留首字後的剩餘字碼 |
| 候選字展開 | 新增可捲動網格，超出第一頁亦可直接選取；長按展開鍵仍可換頁 |
| 查速成碼 | 長按候選查看各字的速成碼 |
| 選字後聯想詞 | 新增離線詞庫後綴候選；例如選「你」後可點「好嗎」。上下文只在記憶體，收起鍵盤／移動游標／輸入符號時清除，可停用 |
| 常用字排序 | 保留本機選字計數，整句只拆成單字學習 |
| 自訂短語 | 手動新增、修改、刪除最多 100 組字母快捷碼；私密欄位不顯示 |

| 純英文補全 | 新增，EN 模式空白鍵保留原字，不自行替換拼字 |
| 英文拼字建議 | 198,308 字離線詞庫、一個編輯距離的點選建議，可停用 |
| Emoji、最近使用及整組刪除 | 保留 3,773 款、9 分類及最多 40 個最近使用記錄 |
| 文字工具 | 手動貼上、全選、複製、剪下；密碼欄停用，不保存剪貼簿歷史 |
| 按鍵及外觀 | 保留主題、數字列、高度、震動、單手、Fold 分體、滑動空白鍵移動游標、長按刪除及大寫鎖定 |
| Samsung AI | 仍然提供系統使用說明與鍵盤選擇器，沒有內置 Samsung 私有引擎 |

## 參考與驗證限制

此環境無法存取 Kaiboard 官方網站／商店介紹，使用者未提供該版本的完整功能描述，因此上表是本專案的實際範圍，**不是已核實的 Kaiboard 官方全部功能對照**。詞庫、排序及操作不保證與 Kaiboard 完全相同。

Robolectric 測試在 JVM 上執行 Android 編輯器與 IME 的真實輸入／提交流程，涵蓋整句、逐字保留、候選網格、自訂短語、英文、聯想詞及私密欄位。這些測試不代表 Samsung 真機操作、Fold 畫面、對話框位置或 TalkBack 已通過；真機驗收見 TESTING.md。

下次接續時先看 BUILD_VERIFICATION.md 的建置結果，再按 TESTING.md 在實體手機完成速成與 Fold 驗收。若要核對全部 Kaiboard 功能，仍需可存取的官方功能介紹或使用者提供的操作清單。
