# 字詞選擇、同碼學習及第三碼頂字（未發佈）

2026-10-25；沿用 0.6.39／versionCode 46。此次改變輸入方式，沒有發佈 APK。

## 操作

預設 `sentence_candidates=false`：候選來自字庫單字、已有詞語及明確自訂詞；
不再把每段最高分單字拼成句子。已有整句引擎保留在「實驗整句候選」開關，
預設關閉。選「單字」後保持該模式，選擇只消耗對應前綴，剩餘碼繼續保留。

`quick_top_out=true`：連續速成開啟、普通中文模式下，在輸入下一碼前，
先檢查延伸碼是否有常用詞、已學詞、自訂詞或英文前綴接得上。
常用詞保留等選；否則每完整兩碼按目前同碼排序上屏，留下未完成單碼及新碼。
例如 `ofc` 可留作「人類」，`ofca` 可選「無錯」，`lwm` 可選「中國」。
三／四碼階段的公共詞前綴採 KINFX 的熱詞門檻 19000；已完成詞最低 3000；
五碼起可以保留一般字庫詞前綴。新近確認過、該拼法仍有正權重的詞亦可保留。
自動頂字不新增學習紀錄。

此開關採速成兩碼優先；使用完整倉頡請關閉頂字或速成。關閉連續速成、
切換英文／「單字」／實驗整句候選亦不會第三碼頂字。大寫英文不受自動頂字處理。
公共字庫詞仍可供選；無法顯示的字由原有裝置字形檢查篩選。

## 本機學習

沿用現有「學習」選項，預設關閉。開啟後：

- 確認單字沿用 `QC:碼:字` 等既有鍵，依長期次數及七日半衰期的近期使用排序。
- 確認整個字庫／自訂詞，新增 `U:模式:完整拼法:詞`。相同模式、相同拼法內優先；
  不同合法拆碼不會無條件共享次數。字庫所有原生別碼仍可輸入。
- 全詞 `W:` 次數只供已知詞的聯想；點選聯想可記住剛完成的已知詞。
  逐字挑字不會從編輯器前文擷取新詞或整句，也不再寫入 `S:` 字序。
- 只在編輯器接受確認後累積。最近一次完成選字的即時重選／刪除可撤回該次正權重；
  同碼重選亦降低被換走選擇的權重。移動游標、開始另一段輸入後不追溯早前選字。
- 關閉學習或受保護欄位不使用／寫入這些個人權重。受保護欄位也不讀自訂詞及置頂。

現有次數、近期、修正及手動詞設定不清除；舊 `S:` 資料留在本機，預設新模式不讀取。
舊 `W:` 不當作任何新拼法的 `U:` 記錄。學習、Layout、appId、版本及簽名設定均沿用。
