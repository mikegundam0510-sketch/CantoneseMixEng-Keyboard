This project uses six reviewed one-to-one glyph pairs in offline TRAIN text:
爲→為, 僞→偽, 檯→枱, 脣→唇, 鍼→針, 衆→眾.
Unicode NFC is applied separately. Original source/rules/provenance remain in
tools/data/clean_ranking/orthography and tools/data/clean_language_models.
No editor text, evaluation gold, keyboard character set or code is changed.
Historical particles without an approved mapping are left unchanged.

The derived statistical character model is recorded in PRIMARY_MODEL_REPORT.json.
